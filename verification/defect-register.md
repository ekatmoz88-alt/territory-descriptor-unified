# Реестр дефектов и расхождений

> **Источник:** итоговый отчёт испытаний от 24.11.2026. Реестр фиксирует наблюдения отчёта, но не подменяет исходный баг-трекинг. Причины, не подтверждённые отчётом или исходниками, не выводятся как установленные.

| ID | Контур | Наблюдаемое расхождение | Категория |
|---|---|---|---|
| BUG-01 | ПОМС / ПОШ ВБД | Смещение даты выдачи на один день при преобразовании UTC ↔ MSK | Данные / интеграция |
| BUG-02 | ПОСС | Значение поля «Пол» теряется при формировании печатной формы | Печать / маппинг |
| BUG-03 | ВБД / ПОМС / ПОСС | Дублирование адресных регистраций при повторном обмене | Целостность данных |
| BUG-04 | ПОСС | Дублирование вкладок при повторном открытии одного досье | UI |
| BUG-05 | ПОСС / ФИАС | Ошибка форматирования поля «Корпус» | Адресные данные / UI |
| BUG-06 | ПОМС 1.22.0.0 | Обрезание элементов управления в форме | UI |
| BUG-07 | Методика испытаний / UI | Терминология интерфейса не согласована с формулировками МИ | Документация / тестирование |

## Интерпретация

- BUG-01 затрагивает обмен между внутренним мобильным контуром ПОМС и контуром ПОШ ВБД. Отчёт фиксирует календарный сдвиг; конкретная реализация преобразования даты требует проверки по коду.
- BUG-02 относится к передаче реквизита из карточки в печатное представление. Не утверждается, что дефект связан с таблицей `print_page_state`.
- BUG-03 фиксирует дубли адресов при обмене. Конкретный ключ дедупликации и алгоритм идемпотентности в отчёте не подтверждены.
- BUG-04 и BUG-06 относятся к поведению UI соответствующих контуров.
- BUG-05 фиксирует некорректное форматирование «Корпуса» в адресном блоке, связанном с ФИАС.
- BUG-07 — несоответствие терминологии UI и МИ.
