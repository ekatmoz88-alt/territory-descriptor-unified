## Ключевые оговорки

- `ConnectionFactory.cs` относится только к SQLite DAL; это не реализация ПОШ ВБД.
- `UmmsSearchPersonResultViewModel.cs` — модель представления результата поиска, не доказательство SOAP-клиента.
- `UmmsNp.cs` в публичном дереве как исходный файл отсутствует. Доступны ссылки на него из диагностической трассировки и сгенерированной документации; этого недостаточно для реконструкции полного класса.
- PostgreSQL-модель из `data-model/` — реконструкция для проверки сценариев, а не производственная физическая схема.
