# Инвентаризация фактической реализации

| Артефакт | Что подтверждает | Чего не подтверждает |
|---|---|---|
| `ConnectionFactory.cs` | Создание/получение подключения к SQLite в слое `DbStationary.Data` | Не подтверждает роль ПОШ ВБД, SOAP или сетевой шлюз |
| `SQLiteCommandEx.cs`, `SQLiteDataReaderEx.cs`, `SQLiteMaps.cs` | Вспомогательные компоненты доступа к данным SQLite | Не подтверждают схему производственной Oracle-БД |
| `UmmsSearchPersonResultViewModel.cs` | Модель UI результата поиска персоны | Не подтверждает сетевой SOAP-вызов, endpoint или авторизацию |
| `UmmsPersonViewModel.cs` | Упоминается среди артефактов библиотеки | Текст исходного файла не представлен в текущем публичном дереве; поля и маппинг здесь не реконструируются |
| `UmmsNp.cs` | Имя файла и вызов `processS2` упоминаются в диагностической трассировке; отдельная HTML-документация описывает генерируемый SOAP proxy | Полный исходный файл не найден в публичном дереве; сведения об операциях сценариев 2–4 в источниках расходятся |
| `UmmsNpImplService` | Упомянут в итоговом отчёте испытаний | Реализация класса/сервиса в проверенном публичном дереве не найдена |

## Единая архитектурная модель

АРМ ППО «Территория» / АРМ «Дешифратор» / ОКР «Дискриптор-14» / Dossier Processing Workstation — одно программное рабочее место. ПОСС, ПОМС и ПОШ ВБД — его внутренние контуры. «Граждане» — функциональная область АРМ. UMMS (`umms-web`) — внешняя система/сервис.

Соответствие ПОСС ↔ `ModuleStationary`, ПОМС ↔ `ModuleMobile` и ПОШ ВБД ↔ отдельный компонент пока не подтверждено и должно проверяться отдельно.
