# MSKTs — Mobile Well-Cementing Control Station

## Scope and system boundary

The supplied operating-manual fragment describes a mobile cementing-control station (МСКЦ) used to monitor and document well-cementing operations in field conditions. It is an industrial measurement and control system, not a component of PPO Territory or ARM Descriptor.

## Purpose and measured parameters

The station is described as recording:
- pressure;
- flow rate;
- density;
- temperature.

It supports real-time operational monitoring of the well-cementing process and processing/documentation of both primary sensor readings and calculated values.

The stated environmental operating range is −40 °C to +60 °C.

## Hardware composition described

The measurement module list includes:
- structural housing with tubing tails and quick-release connections;
- pressure transducer, stated range 40 MPa;
- temperature transducer, stated range −50 °C to +60 °C;
- detection block BD-1;
- BOI-3 density-meter block;
- non-contact density meter IPB-1K;
- mounting cabinet with cable entries;
- RGR-100 flow converter, stated range 0–100 l/s;
- communication cable reels.

The station delivery list includes:
- measurement module;
- remote digital display;
- Spektr 433 radio modem;
- computer;
- KATK software;
- operating manuals for the station and measurement devices.

## Operating sequence

The manual instructs the operator to:
1. connect the display and computer to the measurement module through an i7563 converter;
2. connect the measurement module to a 220 V power supply;
3. prepare the software and operate it in cementing-control mode;
4. provide the customer with a report generated by KATK software.

## Maintenance

After field work, pressure and temperature sensors are removed from their seats, washed to remove cement residue, lubricated at the sealing rings using the specified lubricant, and reinstalled. If a sensor fails, the corresponding seat is closed using the supplied spare plug.
