# ППО «Территория» — техническая документация

> **📘 Documentation website:** [Open Territory Docs](https://ekatmoz88-alt.github.io/territory-docs/)

Репозиторий `territory-docs` содержит детализированные материалы по информационной базе и прикладным компонентам ППО «Территория»: модели Oracle, предметные модули паспортного и миграционного учёта, исходный код, API и связи между ними. Это дополнительный комплект технической документации по ППО «Территория». В рамках проекта АРМ «Дешифратор» документируется как отдельное workstation-приложение со своими компонентами и границами исполнения; историческое обозначение АРМ «Дискриптор» относится к тому же проекту и не образует отдельную систему. Наличие общей проектной принадлежности не означает общего executable, runtime или прямой интеграции.

- [Исходный код и модели](./source-code/index.md) — архитектура проектов, основные модули и соответствие моделей кода таблицам БД.
