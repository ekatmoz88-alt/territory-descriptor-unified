# Физическая структура информационной базы — указатель

Содержимое этой страницы консолидировано в едином документе [«База данных и модели»](./index.md#физическая-структура-и-дополнительные-фрагменты-модели).

В каноническом документе сохранены сведения о физической спецификации, перечне из 381 пронумерованной таблицы, группах объектов, полях и индексах по оглавлению, модели Sybase PowerDesigner, а также все уникальные описания предметных классов из доступных фрагментов.

Число 381 относится к отдельному документальному источнику и не подменяет инвентаризацию 401 таблицы. Причины различия не установлены.
