# Логическая структура информационной базы — указатель

Содержимое этой страницы консолидировано в едином документе [«База данных и модели»](./index.md#логическая-модель-и-предметные-классы).

В канонический документ перенесены оглавление 25 функциональных разделов, сведения о паспорте исходного документа, описание классов ядра (Person, PersonData, Relationship, PersonAttribute, PersonAddress, PersonOrganizationRelation) и границы доступного фрагмента.

Логические классы не приравниваются автоматически к физическим таблицам CORE_*; соответствие требует отдельной сверки модели.
