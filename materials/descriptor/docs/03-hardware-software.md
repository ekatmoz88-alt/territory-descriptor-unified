# ARM Descriptor — Hardware and Software Requirements

The technical-project materials describe the following baseline. These are requirements, not confirmation of equipment delivered or installed.

| Area | Described requirement |
|---|---|
| CPU / memory | Intel Core i7; 16 GB DDR3 |
| Storage | SSD from 128 GB and HDD from 3 TB |
| Graphics / power | GPU with 2 GB DDR3; PSU from 500 W |
| Display | IPS, at least 24 in, 1920×1080 |
| UPS | At least 750 W |
| Scanner | Flatbed, at least 2400 dpi |
| Passport printer | Olivetti PR2 Plus, USB |
| Photo printer | Epson Stylus Photo 1410, A3, continuous ink supply, at least 2400 dpi |
| Laser printer | Monochrome duplex, at least 1200 dpi |
| Laminator | GMP Passport 175 LSI |
| Readers | MRZ reader; contactless ISO/IEC 14443 reader; contact ISO/IEC 7816 reader |

The materials also mention a network filter and a mobile floor-standing air conditioner from 3 kW. Software baseline: Windows 7/8 x64, Microsoft Office, Adobe Photoshop CS6, CorelDRAW X6 and Dr.Web Desktop Security Suite.

Other equipment variants appear in related materials (including Epson V700 Photo and HP LaserJet P3015dn). Do not merge lists from different revisions without checking the originals.
