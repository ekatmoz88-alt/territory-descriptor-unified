# PPO Territory — Historical Platform Requirements

The available technical materials mention the following historical platforms and components:

- Microsoft Windows XP, Vista, 7 and 8.
- Oracle Linux 5.6.
- Debian 6.
- Java Runtime Environment 6.
- CryptoPro CSP 3.6 R2.
- Oracle database technologies in the broader system context.

These versions reflect historical requirements and are obsolete. They must not be treated as current deployment recommendations.

A technical requirement does not prove that a specific version was installed at every site. Actual inventories, patch levels and regional configurations require operational records or system evidence.
