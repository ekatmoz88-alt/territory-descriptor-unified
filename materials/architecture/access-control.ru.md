# Управление доступом

## Разрешить выгрузку

**Назначение.** Разрешение «Разрешить выгрузку» предоставляет пользователю доступ к пункту меню, запускающему процедуру экспорта данных из базы. В исходном руководстве формулировка прямо ограничена разрешением пункта меню выгрузки; она не доказывает сама по себе наличие отдельной проверки полномочий на каждом внутреннем этапе экспорта.

**Связанный процесс.** Согласно разделу 3.2, выгрузка включает три последовательных этапа:

1. поиск обновлённой информации в таблицах БД; в сетевом режиме для обрабатываемой таблицы временно ограничивается доступ других пользователей;
2. оптимизация набора данных для исключения повторяющихся строк;
3. формирование файла выгрузки; операция может существенно нагружать локальную сеть, при этом работа с БД в целом остаётся возможной.

**Область действия разрешения.**
- открыть/использовать пункт меню выгрузки;
- инициировать предусмотренный приложением процесс формирования выгрузки.

**Не подтверждено представленным фрагментом.** Отдельные права на выбор таблиц и категорий данных, запуск экспорта через API/командную строку, просмотр чужих выгрузок, скачивание готовых файлов, настройка расписания, подтверждение операции, журналирование каждого шага и разграничение по подразделениям. Эти возможности нельзя включать в описание реализации без дополнительных материалов.

**Административное управление.** Изменение индивидуальных прав выполняется пользователем, имеющим право администрирования базы данных, через интерфейс списка пользователей. Сами настройки прав, согласно документу, хранятся в отдельном файле в каталоге ПО.

**Проверки для тестирования.**
- пользователь без разрешения не видит или не может использовать пункт меню выгрузки — точное ожидаемое поведение проверить в UI;
- пользователь с разрешением может инициировать экспорт;
- проверить обработку временной блокировки таблицы в сетевом режиме;
- проверить дедупликацию и состав сформированного файла;
- проверить поведение при ошибке поиска обновлений и генерации файла;
- проверить регистрацию имени файла и количества данных в LOG, поскольку эти сведения перечислены в разделе 4.2.

**Трассировка:** руководство пользователя/администратора, разделы 3.2 «Выгрузка данных», 4.1 «Права доступа» (пункт «Разрешить выгрузку»), 4.2 «Протоколы работы программы».
