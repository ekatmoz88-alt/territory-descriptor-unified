Architecture catalogue

Evidence-based architecture catalogue for four separately documented systems. The 10 Mermaid diagrams distinguish documented facts, logical reconstructions and items requiring verification.

Language:
Source MarkdownGitHub folder

How to read these diagrams

  • Documented — directly stated in available project documentation or inspected source excerpts.
  • Derived view — a logical grouping for readability; it is not a recovered deployment configuration.
  • Unverified — protocols, endpoints, ownership, runtime topology or module responsibilities are not established by available evidence.
  • The 17-module count for PPO Territory is mentioned in source materials.
  • Separate system boundaries.
