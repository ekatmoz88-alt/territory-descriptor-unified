Зависимости, конфигурация и границы запуска

Сводка по архивам поставки и конфигурационным файлам. Это описание исторической комплектации, а не инструкция по развёртыванию.

Статус проверки. Установщики и приложения не запускались. Внешняя доступность сервисов не проверялась. Конфигурационные значения рассматриваются как свидетельства из комплекта поставки, а не как актуальные production-настройки.

Состав приложения

КомпонентПодтверждённые сведенияОграничение вывода
Descriptor.exeWindows desktop application, .NET Framework 4.5; пакет содержит WPF-компоненты, TWAIN helper, Tesseract OCR и нативные библиотеки x86/x64.Конфигурация приложения не подтверждает прямое подключение к SOAP или Elasticsearch.
ModuleStationary.exeОтдельный WPF-модуль .NET Framework 4.5, SQLite, словари, печатный компонент и локальная конфигурация FIAS.Локальная БД сама по себе не доказывает синхронизацию с мобильным модулем.
ModuleMobile.exeОтдельный WPF-модуль .NET Framework 4.5, SQLite, словари, конфигурация SOAP UMMS и локальная конфигурация FIAS.URL в конфигурации не подтверждает доступность сервиса или успешную интеграцию.
Elasticsearch / FIASElasticsearch 1.2.1, Lucene 4.8.1, плагины XML и river-csv, предварительно заполненный индекс.Индекс нельзя заменять пустым или удалять lock-файлы без проверки.

Конфигурационные источники

  • Descriptor.exe.config: целевая платформа .NET Framework 4.5; подтверждённой SOAP-строки подключения нет.
  • Descriptor_config.zip → Config.cfg: исторические Windows-пути к растровым шрифтам, архиву, базе данных и Paint.NET.
  • ModuleStationary.exe.config: .NET Framework 4.5 и локальный адрес FIAS/Elasticsearch.
  • ModuleMobile.exe.config: .NET Framework 4.5, конфигурация SOAP UMMS и локальный адрес FIAS/Elasticsearch. Реальные значения адресов не публикуются.

Локальные базы SQLite

Мобильный модуль: User, UserRole, UserAction.

Стационарный модуль: Cases, Dossier, Person, Document, XML-таблицы, таблицы пользователей и аудита.

Это структура приложенных локальных баз, а не доказательство состава промышленной БД или механизма синхронизации.

Linux-скрипт Elasticsearch присутствует, но его настройки используют CMS GC-параметры, отсутствующие в современных версиях Java. Совместимость с современной Java не подтверждена.

Ограничения анализа

  • Приложения и установщики не запускались.
  • Доступность внешнего SOAP-сервиса не проверялась.
  • Предварительно заполненный индекс ФИАС необходимо сохранять целиком.
  • ZIP-предупреждение для пустого каталога Dics/ само по себе не доказывает повреждение исполняемых файлов.
  • Экспериментальный запуск требует изолированной среды и копии исходных данных.

Вывод

Систему следует описывать как набор отдельных Windows-компонентов с различающимися локальными данными и внешними зависимостями. SOAP-интеграция подтверждается конфигурацией мобильного модуля; FIAS/Elasticsearch указан в конфигурациях мобильного и стационарного модулей. OCR и сканирование относятся к комплекту настольного приложения.
