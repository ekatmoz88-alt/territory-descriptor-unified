## Компоненты, охваченные документацией

Обзор программного комплекса содержит отдельные разделы по трём основным направлениям:

- `ModuleMobile` — поиск персон в UMMS, просмотр досье, SOAP-вызовы, сценарии и подготовка экспорта;
- `ModuleStationary` — импорт переданных дел и результатов синхронизации, локальное хранение и работа с SQLite;
- `Printer` / `PassportPaint` — редактирование паспортных макетов, XML-макеты, формирование МЧЗ и печать.

Дополнительно рассмотрены общие библиотеки и модели, файловый обмен через съёмный носитель, шифрование, ФИАС/Elasticsearch, OCR, зависимости и технические ограничения. Это означает, что перечисленные направления отражены в документации; это не означает, что полный исходный код каждого компонента опубликован.

## Выборочные исходные файлы

В репозитории находятся пять выбранных C#-файлов слоя SQLite:

- `sources/DbStationary.Data/ConnectionFactory.cs`
- `sources/DbStationary.Data/SQLiteCommandEx.cs`
- `sources/DbStationary.Data/SQLiteCommandEx_Params.cs`
- `sources/DbStationary.Data/SQLiteDataReaderEx.cs`
- `sources/DbStationary.Data/SQLiteMaps.cs`

Они перенесены как материалы для source-based review, а не как полный исходный проект.

## Что не следует считать перенесённым

В текущем дереве GitHub нет полного исходного кода WPF-комплекса:

- полных деревьев проектов `ModuleMobile` и `ModuleStationary`;
- полного проекта `Printer` / `PassportPaint`;
- всех общих библиотек, моделей, провайдеров, XAML и ресурсов;
- полных решений и проектов Visual Studio (`.sln`, `.csproj`) со всеми зависимостями;
- полной схемы и подтверждённого актуального файла стационарной БД `MainDB.db3`;
- реализации драйвера принтера и набора эталонных тестов для проверки физической печати.

Обзор этих компонентов подготовлен по предоставленным описаниям и выбранным фрагментам исходников. Это не равнозначно полному переносу исходников или завершённому аудиту всей системы.

## Что требуется для полного воспроизводимого архива

1. Оригинальные папки всех проектов или архив с сохранённой структурой каталогов.
2. Решения и проекты Visual Studio, XAML, ресурсы, конфигурации и необходимые библиотеки.
3. Отдельная проверка секретов, паролей, персональных данных, сертификатов и адресов сервисов.
4. Проверка лицензий и прав на публикацию кода и сторонних компонентов.
5. Проверка сборки и сценариев работы в изолированной среде; для PassportPaint — тестирование с поддерживаемым физическим принтером.

## Итог

**Документационные материалы по ModuleMobile, ModuleStationary и Printer / PassportPaint находятся в отдельном репозитории Deshifrator.** В GLOBAL11 эти материалы больше не должны учитываться: там оставлен самостоятельный Oracle GLOBAL11 demo data platform.

При этом в Deshifrator перенесены документация и пять выбранных файлов SQLite data-access, а не полный исходный код всего WPF-комплекса.
