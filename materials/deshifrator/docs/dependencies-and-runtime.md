# Зависимости, конфигурация и границы запуска

## Назначение страницы

Эта страница фиксирует зависимости и параметры, обнаруженные при анализе архивов поставки и конфигурационных файлов. Она описывает историческую комплектацию, а не готовую инструкцию по развёртыванию.

## Состав приложения

| Компонент | Подтверждённые сведения | Что не следует предполагать |
|---|---|---|
| `Descriptor.exe` | Настольное приложение для Windows; целевая платформа .NET Framework 4.5. В комплекте присутствуют WPF-компоненты, помощник TWAIN-сканирования, Tesseract OCR и библиотеки для x86/x64. | Конфигурация самого `Descriptor.exe` не подтверждает прямое подключение к SOAP-сервису или Elasticsearch. |
| `ModuleStationary.exe` | Отдельный WPF-модуль .NET Framework 4.5. В комплекте есть локальная SQLite-база `ModuleStationary.db3`, словари, печатный компонент и параметр локального FIAS-сервиса. | Наличие локальной БД не доказывает автоматическую синхронизацию с мобильным модулем. |
| `ModuleMobile.exe` | Отдельный WPF-модуль .NET Framework 4.5. В комплекте есть SQLite-база `ModuleMobile.db3`, словари, конфигурация SOAP-сервиса UMMS и адрес локального FIAS-сервиса. | Конфигурационный URL не подтверждает доступность сервиса или успешное выполнение интеграции в текущей среде. |
| Elasticsearch / FIAS | В поставке обнаружен Elasticsearch 1.2.1, Lucene 4.8.1, плагины XML и river-csv, а также предварительно заполненный каталог индекса ФИАС. | Нельзя заменять каталог индекса пустым или удалять файлы блокировки без отдельной проверки. |

## Матрица конфигурации

| Источник | Наблюдение |
|---|---|
| `Descriptor.exe.config` | Указывает целевую платформу .NET Framework 4.5; сам файл не содержит подтверждённой строки подключения к внешнему SOAP-сервису. |
| `Descriptor_config.zip` → `Config.cfg` | Содержит исторические Windows-пути к каталогам растровых шрифтов, архива, базы данных и Paint.NET. |
| `ModuleStationary.exe.config` | Указывает .NET Framework 4.5 и локальный адрес FIAS/Elasticsearch. |
| `ModuleMobile.exe.config` | Указывает .NET Framework 4.5, конфигурацию SOAP-сервиса UMMS и локальный адрес FIAS/Elasticsearch. Реальные значения адресов в публичной документации не приводятся. |

## Базы данных SQLite

Состав таблиц в двух приложенных файлах различается:

- **Мобильный модуль:** `User`, `UserRole`, `UserAction`.
- **Стационарный модуль:** `Cases`, `Dossier`, `Person`, `Document`, XML-таблицы и таблицы пользователей/аудита.

Это описание структуры приложенных локальных БД. Оно не является доказательством состава промышленной базы данных, объёма рабочих записей или механизма синхронизации между модулями.

## Технологические зависимости

| Зависимость | Версия / вариант в архиве | Роль |
|---|---|---|
| .NET Framework | 4.5 | Среда настольных приложений |
| SQLite | `System.Data.SQLite` и `SQLite.Interop.dll` | Локальное хранение данных |
| Tesseract OCR | 3.02; нативные библиотеки x86 и x64 | Распознавание текста |
| Elasticsearch | 1.2.1 | Локальный поиск по данным ФИАС |
| Lucene | 4.8.1 | Поисковый движок Elasticsearch |
| Elasticsearch XML plugin | 1.2.1.0 | XML-поддержка |
| Elasticsearch river-csv | 2.0.1 | Импорт CSV |
| Java в комплекте Elasticsearch | Windows JRE 7.0, amd64 | Историческая среда запуска поставленного Windows-комплекта |

В архиве Elasticsearch также присутствует Linux-скрипт запуска. Однако его конфигурационный фрагмент использует параметры CMS garbage collector, отсутствующие в современных выпусках Java. Совместимость Elasticsearch 1.2.1 с установленной современной Java не подтверждена.

## Важные ограничения

- Установщики и приложения в рамках этого анализа не запускались.
- Доступность внешнего SOAP-сервиса не проверялась.
- Конфигурационные адреса и локальные пути являются историческими значениями из поставки, а не подтверждением актуальной инфраструктуры.
- Предварительно заполненный индекс ФИАС следует сохранять целиком при исследовании.
- Предупреждение ZIP о записи каталога `Dics/` относится к метаданным пустого каталога; само по себе оно не доказывает повреждение исполняемых файлов.
- Перед любым экспериментальным запуском требуется изолированная среда и отдельная копия исходных данных.

## Вывод для сопровождения

Систему следует описывать как набор отдельных Windows-компонентов с различающимися локальными данными и внешними зависимостями. SOAP-интеграция подтверждается конфигурацией мобильного модуля; FIAS/Elasticsearch указан в конфигурациях мобильного и стационарного модулей. OCR и сканирование относятся к комплекту настольного приложения. Эти границы важны при подготовке схем, руководств по установке и планов модернизации.
