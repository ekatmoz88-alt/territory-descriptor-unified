System Boundaries

The documentation distinguishes three levels:

  • PPO PAK “Territory” — a separate information system with a web interface, application server and database server.
  • Deshifrator Workstation — a separate desktop application with mobile and stationary software modules.
  • UMMS — a separate external SOAP system. A SOAP client and endpoint configuration are visible in the available materials; the complete runtime flow and deployment topology require further verification.
Publication method. Project requirements, source-code observations, logical reconstruction and unverified hypotheses are kept separate. Unknown details are recorded as limitations or questions rather than filled with assumptions.
Public portfolio documentation · Historical technical context: Scientific Instruments, Inc. (2014–2016). Only materials suitable for public presentation are included.
