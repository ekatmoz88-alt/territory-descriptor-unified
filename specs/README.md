## Идентификация

| Наименование | Роль в документации |
|---|---|
| АРМ ППО «Территория» | Основное/историческое наименование программного комплекса |
| АРМ «Дешифратор» | Наименование рабочего места в проектных и эксплуатационных материалах |
| ОКР «Дискриптор-14» | Наименование опытно-конструкторской работы |
| Dossier Processing Workstation | Англоязычное обозначение того же АРМ |

ПОСС, ПОМС и ПОШ ВБД — внутренние контуры одного АРМ. Их нельзя автоматически отождествлять с программными сборками `ModuleStationary` и `ModuleMobile` без отдельной трассировки по исходникам и спецификациям.
